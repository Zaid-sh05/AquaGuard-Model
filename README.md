# AquaGuard AI Project

AquaGuard AI is an intelligent water network monitoring and management system designed to improve water infrastructure safety and efficiency.

The project uses sensor-based data such as flow rate, pressure, and pipeline measurements to detect abnormal conditions in the water network, including leaks, bursts, theft, and unusual pressure or flow behavior.

Machine learning models are applied to classify system conditions and support early fault detection. The project also includes data files, AI model scripts, documentation, Power BI dashboard, and presentation materials.

## Main Features

- Water network anomaly detection
- Leak, burst, and theft detection
- Flow and pressure data analysis
- Machine learning classification model
- Power BI dashboard visualization
- Project documentation and presentation files

## Project Goal

The goal of AquaGuard AI is to help monitor water distribution networks, detect faults early, reduce water loss, and support smarter decision-making for water infrastructure management.
